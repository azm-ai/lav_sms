Part A

Owner and developer guide

What ShaheenLMS is, how it is built, how to install, customize, deploy and secure it, and what still needs work.

1. What ShaheenLMS is

ShaheenLMS is a web-based management system for schools and colleges. It keeps students, staff, classes, subjects, exams, marks, report cards, timetables and fees in one database, and gives each person a login that only shows what their role needs.

It is built on the open-source lav_sms project (Laravel School Management System) and has been rebranded as ShaheenLMS with a green theme and the TenH Tech credit. It runs in any modern browser; there is no mobile app.

For the institute

Admission, class and section setup, exam records, report cards, tabulation sheets, fee collection and receipts.

For teachers

Class lists, mark entry per subject, comments and skill ratings, marksheets and timetables.

For families

Students and parents log in to see profiles, timetables and published results.

Who uses it

Six roles are active in the seeded system: Super Admin, Admin, Teacher, Accountant, Student and Parent. A seventh type, Librarian, appears in the code but is commented out of the user-type seeder and has no working pages.

5. Local setup, step by step

These steps match how this copy runs on Windows with XAMPP. Run commands in a terminal opened in the lav_sms folder.

  1. Install the tools. XAMPP with PHP 8.1 (MySQL included), Composer, and Git.
  2. Start MySQL from the XAMPP Control Panel and create an empty database named lav_sms in phpMyAdmin.
  3. Install PHP packages: composer install
  4. Create the environment file: copy .env.example to .env, then set: 
    APP_NAME=ShaheenLMS
APP_URL=http://127.0.0.1:8000
DB_DATABASE=lav_sms
DB_USERNAME=root
DB_PASSWORD=
  5. Generate the app key: php artisan key:generate
  6. Create tables and demo data: php artisan migrate --seed
  7. Link the upload folder: php artisan storage:link
  8. Start the app: php artisan serve, then open http://127.0.0.1:8000 and sign in with a demo account (Appendix A).

8. How to customize safely

Keep changes in your own files where possible, commit before each change, and test with every role afterwards.

ChangeWhere and how
School name and logoIn the app: Settings → Name of School, School Acronym, Change Logo. The default logo is public/images/shaheen_lms_logo.svg, returned by Qs::getLogo().
ColoursEdit the variables at the top of public/assets/css/shaheenlms-ui.css (--brand, --brand-strong, --brand-dark). Keep white text only on #15803D or darker for readable contrast.
Footer creditresources/views/partials/footer.blade.php, both the web and the print branch.
App name in the tab titleAPP_NAME in .env, with config/app.php as the fallback.
CurrencyHard-coded as a struck-through "N" (Naira) in payment views such as payments/create.blade.php, edit and receipt. Replace it there, for example with Rs.
Locale and time zoneconfig/app.php: 'timezone' => 'UTC' (set e.g. 'Asia/Karachi'), 'locale' => 'en'. Messages are in resources/lang/en.
States and LGAsAddress fields use Nigerian states and LGAs from StatesTableSeeder and LgasTableSeeder. Replace those seeders for your country before the first migration.

Add a new field (example: student CNIC number)

  1. Create a migration: php artisan make:migration add_cnic_to_student_records, add $table->string('cnic')->nullable();, then run php artisan migrate.
  2. Add 'cnic' to $fillable in app/Models/StudentRecord.php.
  3. Add the input to resources/views/pages/support_team/students/add.blade.php and edit.blade.php.
  4. Add a rule in app/Http/Requests/Student/StudentRecordCreate.php and StudentRecordUpdate.php, and include the field where the controller collects record data.

Add a new page

// routes/web.php, inside the auth group
Route::get('notices', 'NoticeController@index')
     ->name('notices.index')->middleware('teamSA');

Create app/Http/Controllers/NoticeController.php returning view('pages.support_team.notices.index'), make the Blade file extend layouts.master, and add a link in resources/views/partials/menu.blade.php inside the matching @if(Qs::userIs…()) block.

Add a new role

  1. Insert a row in user_types (title, name, level).
  2. Add a userIsX() check, and add the title to the right groups (getTeamSA, getTeamAccount…) in app/Helpers/Qs.php.
  3. Create resources/views/pages/<title>/menu.blade.php; the sidebar includes it automatically by role name.
  4. Protect its routes with a middleware in app/Http/Middleware/Custom, registered in app/Http/Kernel.php.

9. Deployment guide

The deployment steps below are standard Laravel 8 practice. They were not run against a live server for this guide (not verified on real hosting).

Shared cPanel hosting

  1. Choose PHP 8.0 or 8.1 in Select PHP Version.
  2. Upload the project above public_html (for example ~/lav_sms).
  3. Point the domain's document root to ~/lav_sms/public. If you cannot, move public's contents into public_html and fix the paths in index.php.
  4. Create the MySQL database and user in cPanel.
  5. Upload a production .env (checklist below).
  6. In Terminal: composer install --no-dev --optimize-autoloader, php artisan migrate --force, php artisan storage:link, php artisan config:cache.
  7. Turn on AutoSSL for the domain.

VPS (Ubuntu, Nginx)

  1. Install Nginx, PHP 8.1-FPM, MySQL 8 and Composer.
  2. Clone into /var/www/shaheenlms; set the Nginx root to …/public with try_files $uri $uri/ /index.php?$query_string;.
  3. chown -R www-data:www-data storage bootstrap/cache, chmod -R 775 on the same folders.
  4. Run the same Composer and Artisan commands as for cPanel.
  5. Get SSL: certbot --nginx -d school.example.com.
  6. Schedule nightly database and storage/app/public backups to another machine.

10. Security and maintenance checklist

Laravel 8 is end of life. Laravel 8 stopped receiving security fixes in January 2023. Plan the upgrade path 8 → 9 → 10 → 11, one major version at a time. At each step, update composer.json, follow the official upgrade guide, run the tests and click through every role. Replace barryvdh/laravel-dompdf 0.8 with 2.x at the same time.
ItemWhy (verified in code)
☐Delete or change all demo accountsSeeders create six demo logins with the password cj.
☐Make users change default passwordsNew students get the password student; new staff get their role name (e.g. teacher) when the field is left blank. Password resets set these same values.
☐Set APP_DEBUG=falseThe local .env and .env.example both have APP_DEBUG=true, which shows stack traces to visitors.
☐Disable public registrationAuth::routes() exposes /register (it returns HTTP 200). Use Auth::routes(['register' => false]).
☐Restrict timetable record deletionttr.destroy has no role check (chapter 7).
☐Block SVG logo uploadsSettingUpdate accepts svg; an SVG can carry script. Allow png and jpg only.
☐Raise password rulesUserRequest allows passwords of only 3 characters.
☐Back up daily and test restoresThe app has no built-in backup.
☐Apply updates monthlycomposer update within the current major version, then retest.
☐Use HTTPS everywhereLogins and student data travel in every request.

13. Task guides by role

Signing in

  1. Open the school's ShaheenLMS address in a browser.
  2. Enter your username or email and your password, then press Sign in.
  3. Forgot your password? Ask an administrator to reset it. The email reset link needs mail settings in .env (not verified).

Admin and Super Admin tasks

How to admit a student

  1. Open Students → Admit Student.
  2. Step 1, Personal data: full name, address, gender, nationality, state and LGA (all required), plus optional email, phone, date of birth, blood group and photo (JPEG or PNG, up to 2 MB).
  3. Press Next. Step 2, Student data: class, section, year admitted, parent, dormitory and admission number.
  4. Press Submit. The student's first password is student; ask them to change it.

How to create a staff or parent account

  1. Open Users, tab Create New User.
  2. Choose the user type, fill the required fields (name, address, gender, nationality, state, LGA) and optionally a username and password.
  3. Press Submit. If you leave the password blank, it becomes the role name (for example teacher).

How to set up classes, sections and subjects

  1. Classes → Add Class: name and class type.
  2. Sections → Add Section: name, class and form teacher.
  3. Subjects → Add Subject: name, short name, class and teacher.

How to set up grades and exams

  1. Exams → Grades: check the grade bands for each class type (A to F, each with a mark range and remark; for example A = 70–100, Excellent).
  2. Exams → Exam List → Add Exam: name and term (1, 2 or 3). The exam belongs to the current session.

How to print a tabulation sheet

  1. Open Exams → Tabulation Sheet.
  2. Choose the exam, class and section, then press View Sheet.
  3. Press Print Tabulation Sheet to open the printable page, then print from the browser.

How to promote students

  1. Open Students → Student Promotion → Promote Students.
  2. Choose the current class and section, and the class and section to promote to, then load the students.
  3. For each student, choose promote, don't promote or graduate, then submit. Mistakes can be undone under Manage Promotions.

How to build a timetable

  1. Open Academics → Timetables and create a timetable record for a class (and, for exam timetables, an exam).
  2. Open the record with Manage, add time slots, then assign subjects to each day and slot.
  3. Everyone can view and print timetables from the same menu.

Teacher tasks

Teachers see the Academics, Students and Exams menus. They can view class lists, enter marks and view marksheets. They cannot create students or print tabulation sheets.

How to enter marks

  1. Open Exams → Marks.
  2. Choose the exam, class, section and subject, then press Manage Marks.
  3. Type each student's continuous assessment (CA) and exam scores (the total cannot exceed 100), then press Update Marks. Grades, subject positions and term totals are calculated for you.
Seen during testing. In this demo database the current session is 2025-2026, but the seeded students are enrolled in 2018-2019. Manage Marks therefore shows "Record Not Found". The mark-entry grid could not be captured for this guide (not verified).

How to view and print a marksheet

  1. Open Exams → Marksheet, choose a class and section, and press the student's View Marksheet button.
  2. Choose the year to see each exam's results.
  3. Press Print Marksheet for the print layout. Super Admin, Admin, the student and their parent can print; teachers can view only.

Accountant tasks

How to create a fee

  1. Open Administrative → Payments → Create Payment.
  2. Enter the title, choose the class (or leave it empty for all classes), the method and the amount.
  3. Press Submit form. A reference number is generated.

How to collect a fee and print a receipt

  1. Open Payments → Student Payments, choose the class and press Submit. This creates each student's fee records for the session.
  2. In the student's row, open Manage Payments → All Payments.
  3. Under Incomplete Payments, type the amount received in Pay Now and press Pay. Paid and balance update at once; part payments are allowed.
  4. Use Print Receipt for the printable receipt. The PDF download fails on PHP 8.1 until dompdf is upgraded (chapter 11).

Student tasks

  1. See your profile: user menu (top right) → My profile.
  2. See your timetable: Academics → Timetables.
  3. See your results: Marksheet, then choose the year. If the school has locked results, enter your PIN when asked.
  4. Change your password: My Account → Change Password. Do this on your first login.
Seen during testing. With no exam records in the demo data, the student's Marksheet link returns to the dashboard.

Parent tasks

  1. See your children: My Children lists each linked child, with links to their profile and marksheet.
  2. See results: open a child's marksheet; printing is allowed for your own children.
  3. If a child is missing, ask the school to set you as the parent on the child's admission record.

Everyone: My Account

On a phone

The layout adapts to phone screens: the sidebar collapses behind the menu button (top right), tables scroll sideways, and the dashboard totals show two to a row.

14. FAQ and troubleshooting

Marks or student payments say "Record Not Found".
No students are enrolled in the current session. Check Settings → Current Session, and promote students into the new session at the start of each year.
A student cannot see their results.
Check that marks were entered for that exam, and whether Lock Exam is on. When it is on, the student needs a result PIN.
I forgot my password.
A Super Admin can reset it from the user's row menu. The new password becomes student for students, or the role name for staff.
Photos do not appear after upload.
The server is missing the storage link. The developer should run php artisan storage:link.
Receipt PDF shows an error.
Use Print Receipt and the browser's "Save as PDF" until the PDF library is upgraded.
An admin cannot see the Settings or Pins menu.
That is by design: Settings and the PIN menu belong to the Super Admin.
The calendar shows events we never created.
They are sample events from the theme and are not stored in the database.
The page says "419 Page Expired".
Your session timed out. Refresh the page and sign in again.
